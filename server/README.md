# Nebesny Archiv — сервер

Сборка: **Minecraft 1.21.1 + NeoForge 21.1.250**.
Это тонкая серверная папка: моды и конфиги скачиваются автоматически при запуске, вручную класть jar-файлы не нужно.

---

## 1. Что нужно

| Компонент | Требование |
|---|---|
| Java | **Java 21** (JDK или JRE) |
| RAM | 6 ГБ на сервер (для 3–4 игроков), 4 ГБ для LAN-режима |
| Интернет | Нужен при каждом запуске: сервер проверяет обновления пака |
| Аккаунты | Лицензионные Minecraft-аккаунты (по умолчанию `online-mode=true`) |

Проверить Java:

```bat
java -version
```

В ответе должно быть `21.x`.

---

## 2. Установка NeoForge (один раз)

1. Скачайте установщик:
   <https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.250/neoforge-21.1.250-installer.jar>
2. Положите `neoforge-21.1.250-installer.jar` в эту папку (рядом с `start-dedicated.cmd`).
3. Откройте консоль в этой папке и выполните:

```bat
java -jar neoforge-21.1.250-installer.jar --installServer
```

4. Дождитесь окончания. Появятся папки `libraries`, `config` и файлы `run.bat`, `user_jvm_args.txt`.
   Наши `user_jvm_args.txt` и `user_jvm_args-lan.txt` уже настроены — **не перезаписывайте их** установщиком.

---

## 3. Первый запуск

1. Скопируйте `server.properties.example` в `server.properties`:

```bat
copy server.properties.example server.properties
```

2. Примите EULA: откройте `eula.txt` и замените `eula=false` на `eula=true`
   (файл появится после первого запуска; можно создать заранее).
   Текст лицензии: <https://aka.ms/MinecraftEULA>

3. Впишите адрес пака в `pack-url.txt` — одну строку, например:

```
https://raw.githubusercontent.com/ВАШ_НИК/nebesny-archiv/main/packwiz/pack.toml
```

4. Запустите сервер:

- **Выделенный сервер (рекомендуется для 3–4 игроков):** `start-dedicated.cmd`
- **LAN-режим (играете на том же ПК):** `start-lan.cmd`
- **Linux:** `./start-server.sh`

При первом запуске сервер скачает ~200 модов и конфиги. Это займёт несколько минут.
В консоли должно появиться `Done (XXs)! For help, type "help"`.

---

## 4. LAN или выделенный сервер?

### Рекомендация

- **2 игрока, один ПК** → `start-lan.cmd`. Один процесс сервера на 4 ГБ + клиент на 6–8 ГБ.
- **3–4 игрока, ПК может работать постоянно** → `start-dedicated.cmd`. Сервер на 6 ГБ,
  игроки подключаются удалённо. Это стабильнее: мир не зависит от того, кто его создал.
- **Ноутбук/слабый ПК** → выделенный сервер на отдельной машине или аренда.

Не запускайте два сервера одновременно: порт `25565` занят.

---

## 5. Radmin VPN (друзья не в одной сети)

1. Все игроки устанавливают **Radmin VPN**: <https://www.radmin-vpn.com/>
2. Один игрок создаёт сеть (имя + пароль), остальные нажимают «Присоединиться».
3. У хоста в Radmin VPN виден IP вида `26.x.x.x`.
4. Хост запускает сервер. Друзья в Minecraft добавляют сервер:
   **Адрес:** `26.x.x.x` (порт `25565` подставится сам).
5. Если не подключается — разрешите Java в брандмауэре Windows:
   `Панель управления → Брандмауэр → Разрешить приложение → Java`.
   Либо создайте правило для входящего TCP-порта `25565`.

Radmin VPN не требует проброса портов на роутере. Обычный интернет-сервер без Radmin
потребует проброс `25565` и белый IP.

## 6. Права игроков

В консоли сервера (или в игре от оператора):

```
whitelist on
whitelist add Nickname
op Nickname
```

`op` даёт полные права — выдавайте только доверенным игрокам.
Список операторов хранится в `ops.json`, whitelist — в `whitelist.json`.

Если у кого-то пиратский клиент, придётся поставить `online-mode=false` в `server.properties`.
Это отключает проверку аккаунтов: любой может зайти под чужим ником. Для закрытой игры
с друзьями по Radmin VPN это допустимо, но обязательно включите whitelist.

## 7. Обновления

При каждом запуске `start-dedicated.cmd` / `start-lan.cmd` вызывает
`packwiz-installer-bootstrap.jar`, который сверяет пак с `pack.toml` и докачивает изменения.

- Обновлять нужно и сервер, и клиентов.
- Перед крупным обновлением сделайте резервную копию папки `world`.
- Если обновление сломало мир — верните `world` из копии и откатите пак на предыдущую версию.

Ручное обновление (если скрипт не запускается):

```bat
java -jar packwiz-installer-bootstrap.jar -g -s server https://raw.githubusercontent.com/ВАШ_НИК/nebesny-archiv/main/packwiz/pack.toml
```

---

## 8. Резервные копии

Перед обновлением или экспериментами:

1. В консоли: `save-all`, затем `save-off`.
2. Скопируйте папку `world` (и `config`, если меняли настройки).
3. В консоли: `save-on`.

Или просто остановите сервер командой `stop` и скопируйте `world` целиком.
Для автоматизации на Windows подойдёт планировщик задач + `robocopy`.

## 9. Клиент

### Вариант А — XMCL / Prism (packwiz)

1. Импортируйте инстанс из `.mrpack` (лежит в релизах GitHub) **или** создайте
   NeoForge 21.1.250 инстанс и добавьте `packwiz-installer-bootstrap.jar`
   в качестве pre-launch команды:

```
java -jar packwiz-installer-bootstrap.jar -g -s client https://raw.githubusercontent.com/ВАШ_НИК/nebesny-archiv/main/packwiz/pack.toml
```

2. Выделите клиенту **6–8 ГБ RAM**.
3. Шейдеры установлены, но **выключены по умолчанию**. Включайте Iris в настройках видео,
   только если есть запас FPS.

### Вариант Б — мобильный Lite

Lite — это **та же сборка и тот же сервер**, но облегчённый клиент:
удалены 11 тяжёлых клиентских модов (Iris, Distant Horizons, Particle Rain,
Sound Physics, First Person, Not Enough Animations, EMF/ETF, GTBCS, Xaero World Map)
и выставлены низкие настройки. Остаётся 199 модов — это минимум, чтобы видеть все
блоки и предметы сервера.

На Pojav (Poco X5 Pro, 8 ГБ) ожидаемо 15–30 FPS в спокойных местах и 5–15 FPS
у большой базы; первый запуск 3–8 минут. Полной плавности телефон не даст.
Подробная инструкция: `docs/lite-guide.md`. Если телефон не тянет — нужен отдельный
Lite-сервер на 100–150 модов, но это будет другой мир.

## 10. Сюжетные NPC

В паке есть два NPC — **Веста Урбан** и **Мия Тинь**. Они ставятся сами: скрипт
`kubejs/server_scripts/story.js` после старта сервера импортирует их рядом с
точкой появления (у NPC фиксированные UUID, поэтому повторный запуск обновляет
их, а не плодит копии).

В логе должно появиться:

```
[story] Story NPCs placed next to the spawn point (X, Y, Z)
```

Если NPC не появились:

1. Проверьте, что в `config/easy_npc/preset/` лежат `vesta.npc.snbt` и `miya.npc.snbt`.
2. Поставьте их вручную из консоли сервера:

```
easy_npc preset import custom easy_npc:preset/vesta.npc.snbt <x> <y> <z> 3f1c9a52-7d64-4e8b-9a10-5c2f8b6d1e40
easy_npc preset import custom easy_npc:preset/miya.npc.snbt <x> <y> <z> 6b2d4e77-1c85-4f39-8d6a-2e7c1b9f0d53
```

Координаты — рядом с точкой появления; её можно узнать командой
`/execute positioned ~ ~ ~ run ...` или из лога `[story]`.

Проверить, что NPC на месте: `easy_npc list` — должно быть `Total NPCs: 2`.

> Easy NPC после импорта **переписывает** файлы пресетов в своём компактном виде.
> На работу это не влияет, но байты перестают совпадать с `index.toml`, и при
> следующем запуске packwiz заново скачает эти два маленьких файла. Это нормально.
>
> Важнее другое: повторный импорт **обновляет уже поставленного NPC**. Если в
> обновлении пака поменялись реплики или правила, сервер подхватит их при старте
> — вручную NPC переставлять не нужно.

## 11. Удалённое управление (RCON)

Для диагностики удобно управлять сервером по RCON. В `server.properties` включите:

```properties
enable-rcon=true
rcon.password=СВОЙ_ПАРОЛЬ
rcon.port=25575
broadcast-rcon-to-ops=false
```

Готовый клиент лежит в репозитории (папка `tools/`, рядом с `server/`):

```bat
node tools\rcon.mjs "list"
node tools\rcon.mjs "easy_npc list"
node tools\rcon.mjs "stop"
```

> RCON — это полный доступ к серверу. Не оставляйте пароль в `server.properties`
> в открытом репозитории и не открывайте порт наружу: держите его в локальной сети
> или на VPN.

## 12. Частые проблемы

| Симптом | Решение |
|---|---|
| `Unsupported class file major version` | Запускаете не Java 21. Проверьте `java -version` |
| `Failed to download pack` | Нет интернета, неверный `pack-url.txt` или репозиторий приватный |
| `Address already in use` | Порт 25565 занят — закройте другой сервер или смените `server-port` |
| Друзья не видят сервер | Radmin VPN не подключён / брандмауэр блокирует Java / неверный IP |
| Низкий TPS | Уменьшите `view-distance` и `simulation-distance`, не ставьте сервер на слабый ПК |
| Книга квестов пустая | Пак не докачался; проверьте `config/ftbquests` и лог загрузки |
| NPC не появились у спавна | Смотрите раздел 10 «Сюжетные NPC» |
| Краш Alex's Caves при генерации | Не удаляйте **Feature Recycler** — он уже в паке и предотвращает конфликт |

Логи: `logs/latest.log`. При ошибке приложите последние 100 строк и список модов.

## 13. Состав папки

```
server/
├─ pack-url.txt                  ← адрес пака (заполнить)
├─ packwiz-installer-bootstrap.jar
├─ start-dedicated.cmd           ← 6 ГБ, для 3–4 игроков
├─ start-lan.cmd                 ← 4 ГБ, хост играет на этом же ПК
├─ start-server.sh               ← Linux
├─ user_jvm_args.txt             ← 6 ГБ
├─ user_jvm_args-lan.txt         ← 4 ГБ
└─ server.properties.example     ← рекомендуемые настройки
```

NeoForge после установки добавит `libraries/`, `run.bat`, `logs/`, `world/`.
