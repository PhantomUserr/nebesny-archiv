# Lite-клиент: та же сборка, тот же сервер

Lite — это **не отдельный мир и не другая сборка**. Это полный модпак «Небесный Архив»
с теми же контентными модами, что на сервере, но с удалённой тяжёлой клиентской графикой
и низкими настройками. Цель — зайти на **общий сервер**, к которому подключаются ПК-игроки.

> Важно: полностью убрать Create, Aeronautics, AE2, Mekanism, магию, данжи и боссов нельзя.
> Без них клиент не увидит блоки, предметы и сущности сервера. Поэтому в Lite остаётся
> **196 модов** — это минимум для совместимости. Легче только отдельный сервер с урезанным
> набором модов, но тогда это будет другой мир.

---

## 1. Что удалено и что оставлено

### Удалено (11 клиентских модов)

| Мод | Почему |
|---|---|
| Iris | Шейдеры на телефоне не нужны, только едят FPS |
| Iris Flywheel Compat | Работает только вместе с Iris |
| Distant Horizons | Очень тяжёлый рендер дальних чанков |
| Particle Rain | Тысячи частиц дождя/снега |
| Sound Physics Remastered | Дорогая обработка звука |
| First Person Model | Косметика, лишний рендер рук/тела |
| Not Enough Animations | Косметические анимации |
| Entity Model Features (EMF) | Дополнительные модели сущностей |
| Entity Texture Features (ETF) | Случайные текстуры, больше памяти |
| GTBCS Cataclysmic Boss UI | Косметический интерфейс боссов |
| Xaero World Map | Тяжёлая карта мира, много записи на диск |

### Оставлено

- **Sodium** — главный оптимизатор рендера.
- **EntityCulling** — не рисует сущности за стенами.
- **ImmediatelyFast** — ускоряет интерфейс и текст.
- **Tips** — русские подсказки для новичков.
- **Xaero Minimap** — лёгкая миникарта (World Map удалён).
- **Create NoWheel** — чтобы случайно не прокрутить механизм в Create.
- Все серверные/content-моды: Create, Sable, Aeronautics, AE2, Mekanism,
  Ars Nouveau, Spectrum, Theurgy, Neo Vitae, Occultism, Iron's Spellbooks, Goety,
  Cataclysm, Aether, Alex's Caves/Mobs, данжи, боссы и т.д.

## 2. Требования

- Телефон: **Poco X5 Pro 8 ГБ** или лучше.
- **Pojav Launcher** (актуальная версия) + Java 21.
- Свободно **8–10 ГБ** памяти.
- Стабильный интернет; желательно Wi-Fi 5 ГГц.
- Аккаунт Minecraft (для `online-mode=true` на сервере).

На 6 ГБ ОЗУ телефон может загрузить сборку, но Android будет чаще выгружать игру.
На 4 ГБ — скорее всего, не хватит.

## 3. Установка

### Вариант А — импорт `.mrpack` (проще)

1. Скачайте `NebesnyArchiv-Lite-1.0.0.mrpack` из Releases.
2. В Pojav: **Install / Импорт модпака** → выберите файл.
   Если ваша версия Pojav не умеет `.mrpack`, используйте вариант Б.
3. После импорта откройте настройки инстанса:
   - **RAM: 4096–5120 МБ** (не 6+ — Android убьёт процесс);
   - Java: 21;
   - JVM args: `-XX:+UseG1GC -XX:MaxGCPauseMillis=200`.
4. Запустите игру. Первый запуск — 3–8 минут, это нормально.

### Вариант Б — вручную (если Pojav не видит `.mrpack`)

1. Установите в Pojav **NeoForge 21.1.250** для Minecraft 1.21.1.
2. Распакуйте `.mrpack` как zip на ПК.
3. Скопируйте папку `overrides` в папку инстанса Pojav (туда, где лежат `mods`, `config`).
4. Моды из `modrinth.index.json` нужно скачать по ссылкам `downloads[0]` и положить в `mods/`.
   Проще сделать это на ПК: импортировать `.mrpack` в XMCL/Prism, дождаться загрузки модов,
   затем перенести папку `mods` на телефон.
5. Скопируйте `options.txt` из overrides в корень инстанса.

## 4. Настройки Pojav и Minecraft

### Pojav

| Параметр | Значение |
|---|---|
| RAM | 4096–5120 МБ |
| Java | 21 |
| Renderer | Holy GL4ES / Zink (что стабильнее на вашем устройстве) |
| Разрешение | 720p или ниже |
| VSync | Выкл |
| FPS limit | 60 (или 30 для стабильности) |

### Minecraft (уже выставлено в `options.txt`, но проверьте)

| Настройка | Значение |
|---|---|
| Render Distance | **4–6** (начните с 4) |
| Simulation Distance | **4** |
| Graphics | **Fast** |
| Particles | **Minimal** |
| Clouds | **Off** |
| Smooth Lighting | **Off** |
| Ambient Occlusion | **Off** |
| Mipmap Levels | **0** |
| Entity Shadows | **Off** |
| Entity Distance | **50%** |
| FOV | 70 |
| GUI Scale | 2 |
| Shaders | **Off** (Iris удалён) |
| Distant Horizons | **Off** (удалён) |

### Sodium / EntityCulling / ImmediatelyFast

- Sodium: включите `Chunk Rendering`, `Entity Culling`; отключите `Clouds`, `Fancy Graphics`.
- EntityCulling: оставьте значения по умолчанию (проверка сущностей 1–2 тика).
- ImmediatelyFast: не отключайте — он снижает нагрузку на интерфейс.

## 5. Подключение к серверу

1. Хост запускает сервер и Radmin VPN.
2. Вы устанавливаете Radmin VPN, присоединяетесь к сети хоста.
3. В Minecraft: **Multiplayer → Add Server**.
4. Адрес: `26.x.x.x` (IP хоста в Radmin VPN), порт `25565`.
5. Если не подключается:
   - проверьте, что Radmin VPN показывает «Connected»;
   - попробуйте `ping 26.x.x.x` в терминале;
   - проверьте, что сервер запущен и в его логе есть `Done`;
   - на ПК хоста разрешите Java в брандмауэре.

## 6. Ожидаемая производительность

| Сцена | Ожидание |
|---|---|
| Загрузка мира | 3–8 минут |
| Спокойный лес/деревня | 15–30 FPS |
| Большая база с Create | 5–15 FPS |
| Бой с боссом | 5–15 FPS, возможны просадки |
| Память | 3.5–5 ГБ, риск выгрузки Android |

TPS сервера от телефона не зависит: сервер считает мир сам. Но если телефон
не успевает рендерить, у вас будут лаги картинки, а не «тормоза» сервера.

## 7. Типичные проблемы

| Симптом | Решение |
|---|---|
| Вылет при загрузке, `OutOfMemoryError` | Уменьшите render distance до 4, закройте другие приложения, поставьте 5120 МБ |
| Зависает на «Loading world» | Подождите 5–10 минут; проверьте свободную память |
| `Missing registry item` / фиолетовые блоки | В Lite не хватает контентного мода — не удаляйте серверные моды |
| Не подключается к серверу | Radmin VPN, брандмауэр, неверный IP/порт |
| Сильно греется | Ограничьте FPS до 30, снизьте разрешение, снимите чехол |
| Звук трещит | Отключите Sound Physics (он уже удалён), уменьшите звук |
| Краш при входе в измерение | Не хватает памяти; попробуйте перезайти с render distance 4 |

## 8. Честное предупреждение

Даже в Lite на Poco X5 Pro это **не ПК-уровень**. 196 модов, Create-механизмы и боссы
требуют ресурсов. Если телефон не тянет:

1. Играйте на ПК — там полная сборка и все шейдеры.
2. Либо поднимите отдельный Lite-сервер на 100–150 модов и играйте на телефоне
   в отдельном мире. Это уже не тот же сервер, но зато плавнее.

Не удаляйте из Lite серверные моды «для скорости»: клиент перестанет видеть часть
блоков и предметов, а в худшем случае не сможет подключиться.
