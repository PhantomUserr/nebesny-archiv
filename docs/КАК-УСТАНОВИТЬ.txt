Nebesny Archiv 1.0.0 — установка на клиенте
==========================================

Что в архиве
------------
  NebesnyArchiv-1.0.0.mrpack  — сама сборка (файл для импорта в лаунчер)
  verify-instance.ps1         — проверка/починка модов (если что-то не так)
  КАК-УСТАНОВИТЬ.txt           — этот файл

Требования
----------
  Minecraft 1.21.1 + NeoForge 21.1.x, Java 21
  Лаунчер: XMCL (рекомендуется), MultiMC, Prism, Modrinth App — любой,
  который умеет импортировать .mrpack

Шаг 1. Установить сборку
------------------------
  1) Открой лаунчер.
  2) Создай НОВЫЙ инстанс (не обновляй старый!) — в XMCL это
     «Создать экземпляр» → «Импортировать сборку модов» → «Импортировать из файла»
     и указать файл NebesnyArchiv-1.0.0.mrpack.
  3) Дождись, пока скачаются все моды (их 220, ~2 ГБ).
  4) Запусти игру.

Шаг 2. Проверить, что сборка совпадает (если что-то пошло не так)
-----------------------------------------------------------------
  Открой PowerShell в папке с этим архивом и выполни:

      powershell -ExecutionPolicy Bypass -File .\verify-instance.ps1

  Скрипт сам найдёт папку mods в XMCL, скачает эталонный пакет с GitHub
  и сравнит все моды по SHA-1.

  Если найдены отсутствующие или отличающиеся моды — почини одной командой:

      powershell -ExecutionPolicy Bypass -File .\verify-instance.ps1 -Fix

  После этого полностью закрой игру и запусти заново.

Шаг 3. Подключиться к серверу
-----------------------------
  Адрес: 192.168.10.216  (порт 25565)
  Ник: любой, сервер в оффлайн-режиме.
  Если клиент ругается на «неизвестные предметы» (например, neovitae:*) —
  значит моды не совпадают с сервером: вернись к шагу 2 и запусти -Fix.

Частые проблемы
----------------
  * «Missing model / неизвестные предметы» при входе
      -> у тебя другие версии модов. Выполни verify-instance.ps1 -Fix
         (или переустанови инстанс из .mrpack с нуля).
  * Установка обрывается
      -> в папке инстанта удали мод, который скачался с ошибкой, и запусти
         импорт заново; затем verify-instance.ps1 -Fix докачает остальное.
  * Долгий первый запуск
      -> так и надо: XMCL собирает конфиги, рецепты и модели (5-15 минут).
